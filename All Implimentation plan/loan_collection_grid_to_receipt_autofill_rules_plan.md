### कोडमधील तांत्रिक दोष (Technical Root Cause)
`LoanCollectionMaster.tsx` मधील खालील कोड तपासा:

1. **`calculateInterest` मधील चूक (Line 618-620)**:
```typescript
} else {
    const installment = acc.installmentAmount || 0; // ₹ २,०८३ (फक्त मुद्दल हप्ता)
    autoApportion(installment, formData.fees || [], acc, dateStr);
}
```
सिस्टमने `acc.installmentAmount` (₹ २,०८३) ही रक्कम **एकूण ग्राहकाने भरलेली जमा रक्कम (Total Amount Received)** मानून `autoApportion` फंक्शनला पाठवली.

2. **`autoApportion` मधील वॉटरफॉल प्राधान्य (Waterfall Priority) (Line 766-773)**:
```typescript
const interestDue = 2693; // १८९ दिवसांचे व्याज
const interestCollected = Math.min(remaining, interestDue); // Math.min(2083, 2693) = 2083
remaining -= interestCollected; // 2083 - 2083 = 0
const principalCollected = Math.min(remaining, principal); // Math.min(0, 52000) = 0
```
- सिस्टमने ₹ २,०८३ मधून आधी व्याज कापले.
- १८९ दिवसांचे एकूण देय व्याज **₹ २,६९३** होते, त्यामुळे संपूर्ण ₹ २,०८३ व्याजातच संपले!
- मुद्दलासाठी **₹ ०** शिल्लक राहिले!
- परिणामी:
  - पावती तपशीलात **रक्कम (Principal) = ०** दिसू लागले,
  - **मेंबर व्याज = २,०८३** दिसू लागले (जे ग्रिडमधील २,६९३ शी जुळत नाही),
  - आणि **एकूण जमा = २,०८३** झाले!

## २. कोअर बँकिंग अधिकृत वसुली नियम (Core Banking Rules)

सहकारी बँकिंग आणि पतसंस्था नियमांनुसार कर्ज वसुली करताना खालील नियम लागू होतात:

### नियम १: दैनिक घटती (Daily Reducing) कर्जाचा हप्ता कसा बनतो?
दैनिक घटती कर्जामध्ये `InstallmentAmount` (₹ २,०८३) हा **मासिक/त्रैमासिक मुद्दल परतावा (Principal Component)** असतो.
आणि व्याज हे प्रत्यक्ष दिवसांनुसार (१८९ दिवस = ₹ २,६९३) स्वतंत्र आकारले जाते.

म्हणून १ नियमित हप्ता भरताना:
$$\text{एकूण नियमित हप्ता} = \text{मुद्दल हप्ता (₹ २,०८३)} + \text{देय व्याज (₹ २,६९३)} = \mathbf{₹\ ४,७७६.००}$$

### नियम २: थकबाकी नुसार पूर्ण देय वसुली (Full Overdue Recovery)
जर खातेदाराचे १८ हप्ते थकीत असतील (थकबाकी = ₹ ३७,४९४):
$$\text{एकूण देय रक्कम} = \text{थकीत मुद्दल (₹ ३७,४९४)} + \text{देय व्याज (₹ २,६९३)} = \mathbf{₹\ ४०,१८७.००}$$

### नियम ३: केवळ व्याज वसुली (Interest Only Recovery)
जर कर्जदाराला फक्त चालू कालावधीचे व्याज भरायचे असेल:
- **मुद्दल**: ₹ ०.००
- **व्याज**: ₹ २,६९३.००
- **एकूण जमा**: **₹ २,६९३.००**

### नियम ४: मॅन्युअल रक्कम वॉटरफॉल नियम (Custom Amount Apportionment)
जर कॅशियरने हाताने कोणतीही रक्कम टाईप केली (उदा. ₹ ५,०००):
1. **वसुली फी / इतर खर्च**: आधी वजा (₹ ०)
2. **दंड व्याज / सरचार्ज**: आधी वजा (₹ ०)
3. **व्याज (Interest)**: आधी पूर्ण देय व्याज भागवले जाईल = $\min(5000, 2693) = \mathbf{₹\ २,६९३}$
4. **मुद्दल (Principal)**: उर्वरित रक्कम थेट मुद्दलात जमा होईल = $5000 - 2693 = \mathbf{₹\ २,३०७}$
- पावती तपशील आपोआप बनेल: **मुद्दल = २,३०७ | व्याज = २,६९३ | एकूण = ५,०००**!

### ४. वॉटरफॉल कॅल्क्युलेटर दुरुस्ती (Fixing `autoApportion`)
जेव्हा वापरकर्ता **"एकूण जमा रक्कम (Total)"** इनपुटमध्ये स्वतःहून कोणतीही संख्या टाईप करेल:
- सिस्टीम ग्रिडमधील देय व्याज (उदा. ₹ २,६९३) लक्षात ठेवून:
  - `Interest = Math.min(Total, InterestDue)`
  - `Principal = Total - Interest`
  अशी अचूक विभागणी करेल.
