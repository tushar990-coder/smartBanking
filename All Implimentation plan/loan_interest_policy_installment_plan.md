# कोअर बँकिंग कर्ज व्याज धोरण व हप्ता वेळापत्रक (हप्ता चार्ट) - प्रकल्प व्यवस्थापन आराखडा
## Core Banking System (CBS) Loan Interest Policy & Installment Schedule Architecture

---

### १. कार्यकारी सारांश व प्रकल्प व्यवस्थापकाची भूमिका (Executive Summary)
**सहकारी पतसंस्था व बँकिंग नियमावलीनुसार (Cooperative Banking Standards)**, कर्ज खात्याचा हप्ता (Installment / EMI) हा कर्ज योजना मास्टरमध्ये निवडलेल्या **व्याज आकारणी पद्धतीवर (Interest Calculation Method)** आणि **हप्ता प्रकारावर (Installment Type)** पूर्णपणे अवलंबून असतो.

सध्याच्या प्रणालीचे सखोल ऑडिट (System Audit) केले असता, बॅकएंडमधील `LoanScheduleGenerator.cs` इंजिन हे फ्लॅट आणि रिड्युसिंगच्या वेगवेगळ्या पद्धती हाताळते; परंतु **कर्ज अर्ज फॉर्म (Loan Application)** व **कर्ज दर पत्रक (Loan Rate Master)** मधील काही गणितीय सूत्रे व पर्याय सीबीएस मानकांशी सुसंगत करण्याची गरज आहे.

### ३. कोअर बँकिंगमधील ४ प्रमुख व्याज पद्धती (Mathematical Specifications)

```
                       ┌─────────────────────────────────────────┐
                       │       कर्ज व्याज आकारणी पद्धती         │
                       └───────────────────┬─────────────────────┘
                                           │
         ┌─────────────────────────────────┴─────────────────────────────────┐
         ▼                                                                   ▼
┌──────────────────┐                                       ┌───────────────────────────────────┐
│   १. Flat Method │                                       │      २. Reducing Balance Method   │
│   (फ्लॅट पद्धत)  │                                       │          (घटती शिल्लक पद्धत)       │
└────────┬─────────┘                                       └─────────────────┬─────────────────┘
         │                                                                   │
         ▼                                           ┌───────────────────────┴───────────────────────┐
┌──────────────────────┐                             ▼                                               ▼
│ सर्व हप्ते स्थिर     │                ┌─────────────────────────┐                     ┌─────────────────────────┐
│ मुद्दल + व्याज स्थिर │                │ २.१ समान हप्ता (EMI)    │                     │ २.२ समान मुद्दल         │
└──────────────────────┘                │ एकूण हप्ता दरमहा स्थिर  │                     │ मुद्दल स्थिर, व्याज घटते│
                                        │ मुद्दल वाढते, व्याज घटते│                     │ एकूण हप्ता दरमहा घटतो   │
                                        └─────────────────────────┘                     └─────────────────────────┘
```

#### पद्धत १: फ्लॅट व्याज पद्धत (Flat Interest Rate)
- **संकल्पना:** सुरुवातीला घेतलेल्या मूळ मुद्दलावर ($P$) संपूर्ण मुदतीचे ($T$) व्याज एकदाच काढले जाते.
- **एकूण व्याज सूत्र:** 
  $$\text{Total Interest} = \frac{P \times R \times T}{100} \quad (T \text{ वर्षांमध्ये})$$
- **मासिक हप्ता (Flat EMI):**
  $$\text{Installment} = \frac{P + \text{Total Interest}}{N}$$
- **प्रत्येक हप्त्यातील मुद्दल:** $\frac{P}{N}$ (स्थिर)
- **प्रत्येक हप्त्यातील व्याज:** $\frac{\text{Total Interest}}{N}$ (स्थिर)
- **वैशिष्ट्य:** संपूर्ण मुदतीदरम्यान दरमहा मुद्दल आणि व्याज दोन्ही समान राहतात.

---

#### पद्धत २: घटती शिल्लक - समान हप्ता (Reducing Balance - Equated Monthly Installment / EMI)
- **संकल्पना:** पतसंस्थेचे मुद्दल जसजसे परत येते, तसतशी शिल्लक मुद्दल कमी होते. परंतु कर्जदाराला दरमहा **एकच ठराविक रक्कम (Equated Amount)** भरावी लागते.
- **मासिक हप्ता सूत्र (Standard Banking Amortization):**
  $$EMI = \frac{P \times r \times (1+r)^N}{(1+r)^N - 1}$$
  *(येथे $r = \frac{R}{12 \times 100}$ = मासिक व्याजदर, $N$ = एकूण हप्ते)*
- **प्रत्येक महिन्याचे व्याज:** $\text{Interest}_i = \text{Balance}_{i-1} \times r$
- **प्रत्येक महिन्याची मुद्दल:** $\text{Principal}_i = EMI - \text{Interest}_i$
- **वैशिष्ट्य:** पहिल्या महिन्यात व्याज सर्वाधिक आणि मुद्दल सर्वात कमी; शेवटच्या महिन्यात मुद्दल सर्वाधिक आणि व्याज नगण्य.

---

#### पद्धत ३: घटती शिल्लक - समान मुद्दल (Reducing Balance - Equal Principal / Declining Installment)
- **संकल्पना:** मुद्दल दरमहा सारखीच ($P/N$) परत केली जाते, आणि त्या महिन्याचे व्याज हे शिल्लक मुद्दलावर आकारून हप्त्यात मिळवले जाते.
- **दरमहा मुद्दल:** 
  $$\text{Principal}_i = \frac{P}{N} \quad (\text{नेहमी स्थिर})$$
- **दरमहा व्याज:** 
  $$\text{Interest}_i = \frac{\text{Balance}_{i-1} \times \text{Days} \times R}{36500}$$
- **दरमहा एकूण हप्ता:** 
  $$\text{Total Installment}_i = \text{Principal}_i + \text{Interest}_i$$
- **वैशिष्ट्य:** **हप्ता दरमहा कमी-कमी (घटत) होत जातो.** पहिला हप्ता सर्वात मोठा असतो आणि शेवटचा हप्ता सर्वात लहान असतो.

---

#### पद्धत ४: दैनिक घटती पद्धत (Daily Reducing Balance)
- **संकल्पना:** नियमित हप्ता वेळापत्रक न ठेवता, कर्जदाराने प्रत्यक्ष ज्या दिवशी रक्कम भरली त्या दिवसापर्यंतच्या शिल्लक मुद्दलावर दिवसांच्या हिशोबाने व्याज आकारले जाते.
- **व्याज सूत्र:** 
  $$\text{Interest} = \frac{\text{Principal Balance} \times \text{Days} \times R}{36500}$$
- **वैशिष्ट्य:** कॅश क्रेडिट (CC), ओव्हरड्राफ्ट (OD), आणि अनियत परतफेड करणाऱ्या पतसंस्था खात्यांसाठी उपयुक्त.

### ५. अंमलबजावणी आराखडा व सुधारणा (Step-by-Step Implementation Roadmap)

#### टप्पा १: कर्ज अर्ज (LoanApplicationMaster.tsx) मधील फ्लॅट हप्ता कॅल्क्युलेशन दुरुस्ती [तात्काळ]
- `formData.loanRateID` वरून जर योजना "Flat (फ्लॅट)" असेल, तर:
  ```typescript
  const totalMonths = formData.durationMonths || 12;
  const totalInterest = (P * ratePerYear * (totalMonths / 12)) / 100;
  newInstallment = Math.round((P + totalInterest) / n);
  ```
- यामुळे फ्लॅट योजना निवडताच अचूक ₹९,३३३ चा हप्ता येईल, रिड्युसिंगचा ₹८,८८५ येणार नाही.

#### टप्पा २: कर्ज दर पत्रक (LoanRateMaster.tsx) मधील पर्याय अधिक स्पष्ट करणे
- `loanInstallmentType` चे पर्याय:
  1. `समान हप्ता` - Equated Monthly Installment (EMI)
  2. `समान मुद्दल` - Equal Principal (Declining)
  3. `फ्लॅट हप्ता` - Flat Installment
  4. `फक्त व्याज` - Interest Only / Bullet Repayment

#### टप्पा ३: हप्ता चार्ट प्रिव्ह्यू बॅज (UI Enhancements)
- वेळापत्रक (Repayment Schedule) दाखवताना वर ठळक बॅज दाखवणे:
  - उदा. `[पद्धत: Flat (फ्लॅट)] - दरमहा स्थिर हप्ता ₹९,३३३ (मुद्दल ₹८,३३३ + व्याज ₹१,०००)`
  - उदा. `[पद्धत: Reducing समान मुद्दल] - मुद्दल दरमहा ₹८,३३३ स्थिर, हप्ता ₹९,३३३ वरून ₹८,४२० पर्यंत घटणारा`
  - उदा. `[पद्धत: Reducing समान हप्ता] - दरमहा स्थिर हप्ता ₹८,८८५`

### ६. कोअर बँकिंग खातावणी नोंदी (CBS GL Accounting Entries)

#### १. कर्ज वाटप करताना (Loan Disbursement Voucher):
- **नावे (Dr):** कर्जदार कर्ज खाते / वैयक्तिक कर्ज लेजर (Loan Ledger) `₹१,००,०००`
- **जमा (Cr):** बँक खाते किंवा रोख शिल्लक (Bank / Cash Ledger) `₹१,००,०००`

#### २. मासिक हप्ता जमा करताना (Monthly Collection Voucher - Waterfall):
- **नावे (Dr):** रोख खाते किंवा बँक खाते (Cash / Bank) `₹९,३३३`
- **जमा (Cr):** कर्ज व्याज खाते - उत्पन्न (Interest Income Ledger) `₹१,०००`
- **जमा (Cr):** कर्जदार कर्ज खाते - मुद्दल जमा (Loan Principal Ledger) `₹८,३३३`
