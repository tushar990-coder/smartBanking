## १. पार्श्वभूमी व व्यावसायिक निकष (Business Requirement & Objective)

पतसंस्था व सहकारी बँकांमध्ये पिग्मी (दैनिक ठेव) खातेदार अनेकदा दैनंदिन पासबुक किंवा जुने कार्ड घेऊन येतात, ज्यावर त्यांचा **जुना खाते क्रमांक (Old / Legacy Account Number)** असतो (उदा. '१२३', 'P-45', '78' इत्यादी). 

सध्याच्या प्रणालीत नवीन १४ अंकी सीबीएस (CBS) खाते क्रमांक दिसतो, परंतु:
1. ऑपरेटरला पिग्मी खात्याचा जुना नंबर शोधता येत नाही.
2. एकाच कर्जदाराचे २-३ पिग्मी खाती असल्यास जुन्या नंबरवरून नेमके कोणते खाते आहे हे ओळखणे अवघड होते.
3. जर कर्जदाराचे पिग्मी खाते कुटुंबातील व्यक्तीच्या किंवा जामीनदाराच्या नावावर जुन्या नंबरने असेल, तर ते जुन्या नंबरने शोधण्याची सुविधा हवी आहे.

**उद्दिष्ट:**  
कर्ज वसुली फॉर्ममधील **'पिग्मी ठेव कर्ज समायोजन (Pigmy Transfer Adjustment)'** कार्डमध्ये जुन्या खाते क्रमांकाने (Old Account Number / Legacy Account Number) जलद शोध (Instant Search & Filter) घेण्याची आणि खात्याची जुनी नोंद थेट सिलेक्ट करण्याची सुविधा देणे.

## २. कार्यप्रणाली व डिझाइन तपशील (Workflow & UI/UX Design)

### २.१ ड्रॉपडाऊनमधील स्पष्ट दर्शक (Clear Dropdown Option Display)
पिग्मी खात्याच्या ड्रॉपडाऊन पर्यायात १४ अंकी सीबीएस नंबरसोबत जुना नंबर ठळकपणे दर्शविला जाईल:
$$\text{[14-Digit CBS No]} \quad \mathbf{[जुना\ क्र:\ OldAccountNo]} \quad - \quad \text{योजना (शिल्लक: ₹...)}$$
* *उदाहरणार्थ:* `001-301-0000002-0 [जुना क्र: 104] - दैनिक ठेव (शिल्लक: ₹3,550.00)`

### २.२ जुना नंबर इन्स्टंट सर्च इनपुट (Instant Search by Old Account No)
कार्डच्या सुरुवातीला एक सुटसुटीत शोध इनपुट (Search Box) दिला जाईल:
* **लेबल:** `🔍 जुना पिग्मी खाते क्र. शोधा (Search Old A/c No.)`
* **प्लेसहोल्डर:** `उदा. 104 किंवा जुना नंबर टाका...`
* **ऑटो-फिल्टर:** ऑपरेटरने जुना नंबर टाईप करताच:
  1. जर चालू कर्जदाराच्या खात्यांमध्ये तो नंबर असेल, तर ते खाते **आपोआप सिलेक्ट** होईल.
  2. चालू कर्जदाराकडे तो नंबर नसल्यास, संपूर्ण बँकेतील सर्व पिग्मी खात्यांमध्ये शोध घेतला जाईल (Third-Party / Family Pigmy Search).

### २.३ बॅज व खात्री दर्शक (Selected Account Badge Indicator)
खाते निवडल्यानंतर स्क्रीनवर खालीलप्रमाणे आकर्षक बॅज दिसेल:
* `🏷️ जुना खाते क्र.: 104` (जांभळा ठळक बॅज)
* `एकूण ठेव: ₹3,550.00`
* `वर्गपात्र शिल्लक: ₹3,550.00` (हिरवा ठळक बॅज)

## ४. तांत्रिक रचना व API अपडेट्स (Technical Architecture & API Changes)

### ४.१ बॅकएंड API: `PigmyAccountsController.cs`
सध्या `GET /api/PigmyAccounts` मध्ये `search` पॅरामीटर उपलब्ध नाही. यामध्ये `[FromQuery] string? search` जोडण्यात येईल:
```csharp
if (!string.IsNullOrWhiteSpace(search))
{
    string sTerm = search.Trim();
    string digitsOnly = new string(sTerm.Where(char.IsDigit).ToArray());
    query = query.Where(p => 
        p.AccountNo.Contains(sTerm) ||
        (digitsOnly.Length >= 2 && p.AccountNo.Contains(digitsOnly)) ||
        (p.OldAccountNo != null && p.OldAccountNo.Contains(sTerm)) ||
        (p.LegacyAccountNumber != null && p.LegacyAccountNumber.Contains(sTerm)) ||
        (p.PreviousAccountNo != null && p.PreviousAccountNo.Contains(sTerm)) ||
        (p.Customer != null && (
            p.Customer.FirstName.Contains(sTerm) || 
            p.Customer.LastName.Contains(sTerm) || 
            (p.Customer.MobileNo != null && p.Customer.MobileNo.Contains(sTerm)) || 
            (p.Customer.CIFNo != null && p.Customer.CIFNo.Contains(sTerm))
        ))
    );
}
```
* **फायदा:** ऑपरेटर जुना नंबर (उदा. "104") टाईप करेल तेव्हा `OldAccountNo`, `LegacyAccountNumber` आणि `PreviousAccountNo` या तिन्ही फील्ड्समधून अचूक खाते शोधले जाईल.

### ४.२ फ्रंटएंड: `LoanCollectionMaster.tsx`
1. `customerPigmyAccounts` मॅप करताना `oldAccountNo` व `legacyAccountNumber` फिल्टरिंगसाठी उपलब्ध करून देणे.
2. `pigmyOldAccSearchQuery` स्टेट तयार करून इनपुट बदलताच तात्काळ मॅचिंग खात्याची निवड करणे.
3. जर कर्जदाराच्या स्वतःच्या खात्यात जुना नंबर सापडला नाही, तर `searchPigmyAccountsApi(query)` द्वारे बँकेतील इतर खातेदाराचे पिग्मी खाते शोधून आणणे.
4. पावती जतन करताना `transferFromPigmyAccountNo` आणि `sourcePigmyAccountID` अचूक पाठवणे.

### ४.३ छापील पावती व व्हॉट्सॲप मेसेज: `LoanCollectionReceiptPrint.tsx`
पावतीवर पिग्मी नंबरसोबत जुना नंबर असल्यास तो दर्शविला जाईल:
* `पिग्मी खाते क्र.: 001-301-0000002-0 (जुना क्र.: 104)`
